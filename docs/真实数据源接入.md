# 衡鉴智考真实题库数据源

入口：智能题库 → 多数据源扩充。选择目标课程、数据源和题型，留空关键词可浏览原题；确认答案后选择入库。

## 已接入

| 数据源 | 数据内容 | 授权与原始资料 |
| --- | --- | --- |
| Open Trivia DB | 英文科学、常识、计算机单选及判断题 | [官方 API 文档](https://opentdb.com/api_config.php)，CC BY-SA 4.0 |
| GSM8K | 英文数学应用题、最终答案与推理过程，使用 test 分片 | [GitHub 原始仓库](https://github.com/openai/grade-school-math)，[MIT 许可证](https://github.com/openai/grade-school-math/blob/master/LICENSE)；上游已归档，用作固定数据集 |
| MBPP | Python 编程题、参考实现与测试用例，使用 sanitized 子集 | [Google Research MBPP](https://github.com/google-research/google-research/tree/master/mbpp)，数据遵循仓库 [README](https://github.com/google-research/google-research) 的 CC BY 4.0 授权 |

适配器将原始内容转换为本项目题型，并保留来源、原题 ID、语言、许可证、采集时间。没有复制上游应用代码；MBPP 参考代码和测试用例只作为文本展示，不自动执行。

## 使用规则

- 数据均为英文原题；英文关键词按题干与学科匹配。没有自动翻译或语义扩写。
- OpenTDB 官方 API 不提供全文搜索，系统在实时取得的最多 50 道题中筛选；无结果时可更换关键词。
- 每个来源每次最多返回 20 道候选题；GitHub 数据集缓存到 `backend/uploads/open-data-cache/`，磁盘缓存有效期 24 小时，内存缓存有效期 1 小时。
- 同一课程内按去除标点与空白后的题干查重。导入结果返回新增和跳过数量。
- 原有学科网、MOOC 等选项是网页检索入口，尚未取得其专用题库 API 授权；结果仅供资料参考，禁止作为完整试题直接导入。系统已去除原先没有测量依据的“质量分”。
- 重新分发开放题目时，请保留来源及对应署名、许可条款；尤其留意 OpenTDB 的相同方式共享要求。

## 部署与排查

沿用现有 FastAPI、httpx 和 SQLAlchemy，无需额外 API 密钥或新依赖。启动后自动创建 `question_provenance` 表，不修改原有题目。

默认直接访问白名单上游地址。若部署网络要求使用系统代理，设置 `DATA_SOURCE_USE_ENV_PROXY=true` 后重启后端。请求失败会逐源显示，不会用虚构题目填充；一次失败后有限重试一次。禁止通过参数指定任意远程下载地址。

```powershell
$env:PYTHONPATH='backend'
backend\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v
npm --prefix frontend run build
```

回归检查覆盖答案选项映射、来源元数据保存、重复导入幂等性和网页资料排除。真实联网检查还需确认源站在当前部署网络可达。
