# 衡鉴智考前端视觉与截图指南

本项目的管理主页由 React、CSS 和内联 SVG 构成。立体平台、目标图标、边框、网格、趋势线、环形图及文字均可直接修改源码；页面没有使用整页截图或截图裁剪作为界面元素。

## 视觉结构

| 区域 | 源码 | 可编辑内容 |
|---|---|---|
| 管理主页 | `frontend/src/pages/CommandCenter.jsx` | 横幅文案、矢量平台插图、指标、考试列表、趋势图、异常分布及监控卡 |
| 科技风样式 | `frontend/src/pages/command-center-v2.css` | 深蓝底色、星点网格、霓虹线、切角面板、尺寸与响应式布局 |
| 教师、学生首页插图 | `frontend/src/components/PortalArt.jsx` | 教学与能力成长的内联 SVG 插图 |
| 共用视觉规范 | `frontend/src/styles-unified.css` | 侧栏、页头、卡片、表格、按钮、空状态 |
| 截图工具 | `tools/capture_pages.py` | 角色、路由、截图尺寸与画廊生成 |

首页考试数、监考事件及资源占用数据为演示内容。页面中的“演示数据”标注保留在源码里，接入真实服务时应将静态数组替换为 API 数据。

## 生成全部页面截图

先按根目录 README 初始化前后端依赖与演示数据库。截图库使用 Playwright Chromium，页面截图保存在本地 `screenshots/`，不会加入 Git。

在项目根目录打开三个终端，依次运行：

```powershell
# 终端一：后端
backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8012

# 终端二：前端
$env:HENGJIAN_API_URL = 'http://127.0.0.1:8012'
npm --prefix frontend run dev -- --host 127.0.0.1 --port 5187 --strictPort

# 终端三：截图
$env:HENGJIAN_BASE_URL = 'http://127.0.0.1:5187'
$env:HENGJIAN_API_URL = 'http://127.0.0.1:8012'
$env:HENGJIAN_OUTPUT_DIR = (Join-Path (Get-Location) 'screenshots\latest')
python tools\capture_pages.py
```

需要安装 `playwright` 并执行 `python -m playwright install chromium`。非 Windows 环境请将后端 Python 路径替换为本机虚拟环境路径。

脚本按管理员、教师、监考员和考生的演示账号访问全部 44 个页面视图。输出目录包含每页 PNG、`manifest.json` 和可点击的 `index.html`。打开 `index.html` 即可逐页查看完整截图。

只检查指定页面时，可以设置：

```powershell
$env:HENGJIAN_CAPTURE_ROLES = 'admin'
$env:HENGJIAN_CAPTURE_ROUTES = 'home,print-management,tag-management'
python tools\capture_pages.py
```

## 修改入口

- 调整主页视觉：编辑 `CommandCenter.jsx` 中的平台 SVG 路径、指标数组和面板结构，再调整 `command-center-v2.css` 中的定位、配色和响应式断点。
- 调整其他页面的共用样式：编辑 `styles-unified.css`。特定模块保留自己的页面级样式，避免全局修改破坏表单和图表。
- 调整教师或学生首页插图：编辑 `PortalArt.jsx` 的 SVG 路径和 `variant` 颜色。
- 验证改动：运行 `npm --prefix frontend run build`，再用截图脚本复拍并检查 `manifest.json` 的 `errors` 字段。
