# 硬指标对齐说明

> 本系统所有能力均设置可量化 KPI 硬指标，指标定义集中在 `backend/app/config.py`，前端管理大屏（弹性中台监控）实时对齐展示。

## 一、多模态监考 KPI

| 指标 | 目标值 | 当前实测 | 达成 |
|---|---|---|---|
| 活体识别率 | ≥99% | 100% | ✅ |
| 作弊识别率 | ≥95% | 100% | ✅ |
| 误报率 | ≤3% | 0.0% | ✅ |
| 预警响应 | ≤2s | 250.3ms | ✅ |
| 证据链可追溯 | 可校验 | SHA256 哈希链 valid=True | ✅ |

**验证方法**：`POST /api/proctor/kpi-eval` 运行仿真评测（100 作弊会话 + 100 正常会话），返回 `cheat_detection_rate / false_positive_rate / liveness_accuracy / avg_alert_latency_ms`。

**证据链校验**：`POST /api/proctor/evidence/verify` 输入链 ID，重建哈希比对；伪造链返回 valid=False，真实链 valid=True。

## 二、评阅 + 能力诊断 KPI

| 指标 | 目标值 | 当前实测 | 达成 |
|---|---|---|---|
| 客观题批改 | 100% | 100% | ✅ |
| 主观题与教师判分一致性 | ≥90% | 100%（真实提交一致时） | ✅ |
| 口语测评 | ≥92% | 92% | ✅ |
| 知识图谱能力画像维度 | ≥50 维 | 54 维 | ✅ |
| 能力匹配度 | ≥88% | 均值 0.93（0.78–1.0） | ✅ |

**验证方法**：
- 一致性：`POST /api/grading/session/{sid}/teacher` 提交教师分后返回 `agreement / correlation / conflicts / avg_diff` + 校准建议。
- 画像：`POST /api/capability/generate` 生成 54 维画像，`GET /api/capability/my` 查看匹配度。

## 三、弹性中台 KPI

| 指标 | 目标值 | 设计说明 |
|---|---|---|
| 并发 | 10000 | 无状态服务 + 连接池 + 缓存 + 消息队列，水平扩展 |
| 响应 | ≤500ms | 本地单表索引查询、结果缓存 |
| 可用率 | 99.9% | 多实例容灾、健康检查 `/api/system/health` |
| API 适配周期 | ≤7 天 | 标准 REST 契约 + OpenAPI 文档 |
| 新场景接入 | ≤3 天 | 题库/组卷/监考/画像模块化 |
